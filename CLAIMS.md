# Claim Ledger

Every headline claim in the manuscript (`paper/main_v2.tex`), mapped to its
stated value, the place it appears in the paper, the script and committed data
that regenerate it, and the `verify.py` check that enforces it.

Run `python verify.py` to recompute all of these from committed data at once.
Line numbers refer to the `paper/main_v2.tex` version committed with this ledger.

Legend for "Regenerated by":
- **verify.py** recomputes the value from a committed derived file.
- The **source script** is what originally produced the derived/committed data
  (run it in the full-reproduction path; see `QUICKSTART.md`).
